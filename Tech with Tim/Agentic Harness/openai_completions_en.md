| Field | Description |
| --- | --- |
| `id` | Identifier of the generated response. |
| `choices` | List of possible model responses. |
| `finish_reason` | Reason why generation stopped (`stop`, `length`, etc.). |
| `index` | Index of the response in the `choices` array. |
| `logprobs` | Information about the probabilities of generated tokens, if available. |
| `message` | Object containing the message generated by the model. |
| `message.role` | Role of the message, here `assistant`. |
| `message.content` | Final text intended for the user. |
| `message.refusal` | Optional indication that the model refused to answer. |
| `message.annotations` | Optional annotations associated with the content. |
| `message.audio` | Optional audio data. |
| `message.function_call` | Information about a function call, depending on the format used. |
| `message.tool_calls` | List of optional tool calls. |
| `message.reasoning` | Optional reasoning text returned by the model or implementation; this is a non-standard field. |
| `created` | Creation date as a Unix timestamp. |
| `model` | Name of the model used. |
| `object` | Type of the returned object, here `chat.completion`. |
| `metadata` | Optional additional metadata. |
| `moderation` | Optional moderation-related information. |
| `service_tier` | Service tier used, if applicable. |
| `system_fingerprint` | Identifier associated with the inference system configuration. |
| `usage` | Token usage statistics. |
| `usage.completion_tokens` | Number of tokens generated by the model. |
| `usage.prompt_tokens` | Number of tokens provided as input. |
| `usage.total_tokens` | Total number of tokens used. |
| `usage.completion_tokens_details` | Additional details about generated tokens, if available. |
| `usage.prompt_tokens_details` | Additional details about input tokens, such as cached tokens or tokens associated with images or audio. |
